# GEMINI.md - Project Context

This directory is a personal learning hub and resource repository for mastering marketing from a beginner level. It is designed to build a "Full-Stack Marketing" foundation by combining timeless psychological principles with modern digital distribution strategies.

## Directory Overview

The purpose of this directory is to store curated resources, learning paths, and eventually implementation notes for marketing projects. It focuses on:
- **Strategy & Psychology:** Understanding persuasion and empathy.
- **Modern Execution:** Digital marketing literacy (SEO, SEM, Analytics).
- **Growth & Product Marketing:** Scaling and go-to-market strategies.
- **Copywriting:** Direct-response and content writing.

## Key Files

- **`marketing_resources.md`**: The primary curriculum. It contains a curated list of books (e.g., Cialdini, Godin), digital courses (e.g., Google Digital Garage), and a structured 3-phase learning path (Foundation, Technical Literacy, and Implementation).

## Usage

This directory should be used to:
1.  **Track Learning Progress:** Follow the phases outlined in `marketing_resources.md`.
2.  **Expand Knowledge:** Add new notes, case studies, or summaries of the recommended books and courses.
3.  **Project Implementation:** When moving to the "Implementation" phase, this directory can store landing page drafts, campaign ideas, and results from real-world experiments.
